The schedule page is the third configuration tab. space moves the position through off, while awake and wake then ping. Moving into or out of wake then ping hands the terminal to the platform's elevation prompt and takes it back afterwards. A refusal leaves the position as it was and is reported in the header's error line. Each slot lists its newest run for every account it pinged. A missed boundary shows the predicted boundary and then the one the ledger reported.

The Anthropic subscription was turned off on the providers page while the machine was set to wake, so the marker dropped and the wake still fires. The position row flags it and offers x to stop waking, which asks for elevation. Below it, a slot being added is refused beside itself and cannot be saved, because its ping lands inside the window the 12:20 ping opens.
